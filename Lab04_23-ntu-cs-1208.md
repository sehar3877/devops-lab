### Short Answers:

* **What is origin/main, and when is it wrong?**  
  `origin/main` is basically a local tracking reference that shows where the `main` branch was on the remote server the last time we checked or communicated with it[cite: 10]. It can become outdated or wrong if someone pushes new changes to the server and we don't run a fetch, because it doesn't update automatically on its own[cite: 10].

* **Name the three repositories involved in Task 4 and say which you can write to.**  
  1. `upstream` (the original class repository) - we can only read from it, no write access[cite: 15].  
  2. `origin` (our personal fork) - we own this one and have full permission to write and push to it[cite: 15].  
  3. `your clone` (the local copy on our laptop) - which has both of these remotes configured[cite: 15].

* **Why was the force-push in Task 7.6 acceptable, when Lab 03 told you never to force-push?**  
  It was okay here because that branch only exists in my personal fork, and nobody else is working on it or has based their code on those commits[cite: 16]. Plus, using `--force-with-lease` adds safety by refusing if the remote fork changed unexpectedly[cite: 16].
